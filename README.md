# .github

Default community health files for all [ScenevaLabs](https://github.com/ScenevaLabs) repositories
(code of conduct, issue and pull request templates). A repository that has its own file overrides
the default here.

ScenevaLabs repolarının ortak topluluk dosyaları (davranış kuralları, issue ve PR şablonları).
Kendi dosyası olan repo buradakini geçersiz kılar.
